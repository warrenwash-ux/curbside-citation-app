Code sections below are starter examples only — replace with your department's actual current code book before relying on them for real citations.

Boot & courtesy fees

Default amounts

Used to pre-fill the boot fee when booting a vehicle, and the reduced amount when issuing a Courtesy Late Fee instead of a full citation. Both are editable per-instance too.

Meter feed (optional)

Connect a real metering vendor

The "Expired Meters Nearby" list on Home is a simulated demo feed — there's no generic public API for live meter-expiry data. A real feed comes from whichever vendor runs the meters in your city (e.g. ParkMobile, Passport, Flowbird) via their enforcement-side API, set up through a vendor/city contract. The fields below are placeholders for when that's in place.

AI recognition (optional)

Connect your Anthropic API key

Enables accurate plate reading and vehicle make/model/color recognition from photos — same bring-your-own-key pattern as your other tools. Costs apply on your own Anthropic account, typically a small fraction of a cent per scan. Without a key, the app still works using the basic on-device scanner and placeholder vehicle data.

Owner name, registration validity, and payment status stay simulated regardless of this setting — those require an actual DMV/payment-vendor data agreement, not an AI model.

Live sync (optional)

Connect Supabase

Mirrors every citation in real time across every officer's phone. See the SQL setup notes in the file's source comments to create the table first.

Low-contact enforcement

Stealth mode

Disables the vibration and screen flash on a successful scan, so nothing signals a scan just happened. Build the citation from a distance, then approach only to place it.

Auto-print on issue

Automatically opens the print screen the instant a citation is issued, so the only thing left to do is walk up, place it, and leave.

Mail filing window

When a vehicle drives off before the citation can be placed, many jurisdictions require the citation be mailed to the registered owner within a set number of days instead of being voided — verify this is actually allowed under your department's ordinance before relying on it; some jurisdictions require physical service instead.

Printing

Receipt width

Tap Print on any citation and your device's normal print screen opens — pick whichever printer is already paired or on the same WiFi network there (this is how AirPrint and most field/receipt printers work on iPhone/iPad). This setting just controls how the receipt is laid out for that print.
